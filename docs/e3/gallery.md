# E3-G1 · galería de medios

La galería se construye como vista transitoria de los `resource`, `entity`, `placement`, `group`, `collection` y `workspace` del snapshot A3. Usa `resourceId` como clave: un recurso aparece una sola vez aunque varias entidades, placements o workspaces lo representen. Las representaciones conservan el `entityId`, ubicación, grupos anidados, colección y etiquetas. El orden es imágenes primero y videos después; el mismo catálogo alimenta los filtros por workspace, grupo, colección, etiqueta y tipo. El proyecto activo es el alcance de proyecto, porque el host mantiene una única sesión de proyecto abierta.

El explorador no duplica archivos ni mantiene un índice alterno. Las imágenes locales se leen bajo demanda, con límite de 4 MiB para preview; el URL remoto nunca se descarga. Un video local solo se lee al activar «Reproducir recurso local», con límite de 32 MiB. Los enlaces remotos se conservan como referencias. No se genera todavía una caché persistente de thumbnails ni un poster para video. Si un recurso no tiene representation, «Mostrar en lienzo» permite elegir workspace y crea un nodo que referencia el mismo resource. Si hay varias representaciones, se puede abrir cada workspace donde existe.

Un mount solo aparece en la galería a través de un recurso multimedia que ya está referenciado en el snapshot del proyecto. A3 no enumera ni recorre carpetas montadas. La operación de catálogo requiere `mount.index`; la inspección/preview del archivo además requiere `mount.read` y una binding local aprobada para ese `mountId`. Un clone no obtiene acceso por incluir una referencia en el proyecto. La raíz ausente, cambiada o sin concesión permanece indicada en la tarjeta y no reemplaza el descriptor.

La suite focalizada verifica orden, deduplicación, asociaciones de grupos anidados, colecciones, etiquetas, filtro por workspace, referencias remotas sin descarga, preview de imagen sin archivos nuevos, carga explícita de video y mounts con/sin permiso efectivo. A3-025 tiene evidencia automatizada de contrato/store; la navegación visual del panel debe validarse en la aplicación con una aceptación de interfaz.
