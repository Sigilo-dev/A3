# Matriz de compatibilidad E0

Fecha de corte: 2026-10-14. Fuente de alcance: `A3_ESPECIFICACION_MAESTRA.md` 1.0.0, especialmente §§4, 28–33. Esta matriz sintetiza las diez comprobaciones de §30; no certifica criterios completos de §29. “Ejecución” se refiere a los harness y fixtures citados, no a una aplicación A3. Cada fila separa resultado ejecutado, respaldo documental, acción pendiente, bloqueo externo y trabajo no probado.

## Lectura de la matriz

- “Parcial” describe un subcaso del spike y no significa que el criterio A3 relacionado esté aprobado.
- “Solo documentación” acredita que la API o condición está descrita por una fuente oficial, no que A3 la haya ejecutado.
- “Requiere cuenta/acción humana” identifica desbloqueos fuera del harness; no se usaron credenciales ni se abrió sesión por otra persona.
- No se observó un bloqueo externo general del servicio ChatGPT o del app-server. El único bloqueo de red concreto fue la descarga de un tema remoto de Structurizr por DNS; el harness lo evitó conservando el modo local.
- El corte real de energía no se ejecutó y queda como no verificado hasta disponer de un laboratorio controlado. La prueba de aislamiento OS queda no verificada hasta implementar un launcher real. No se declara que se haya probado un sandbox por la existencia de documentación.
