# Dependencias y runtimes candidatos tras E0

Inventario a 2026-10-14. Los pins siguientes identifican artefactos de spikes reproducibles, no una lista aprobada para distribución. La existencia de un lockfile o una ejecución local no autoriza redistribución ni garantiza compatibilidad de producción. La especificación maestra §4 sigue siendo la autoridad para las tecnologías aprobadas; esta tabla propone versiones/artefactos, sin modificar sus DEC.

## Paquetes o runtimes no cubiertos por E0

`TypeScript`, `electron-vite`, `electron-builder`, `pdf-lib`, el Git distribuido/ejecutado por A3, MCP SDK, Zustand, Radix, Dagre, MiniSearch, Handlebars y Rough.js aparecen en §4, pero no tienen una versión fijada y comprobada por estos spikes. No proponer versiones por suposición. E1/E2/E3/E5/E6 deberán fijarlas al crear cada módulo y revisar compatibilidad/licencias en ese momento. Git y binarios Electron tienen obligaciones propias y no se heredan de la licencia de su wrapper.

El control de licencias debe formar parte del lock/build real de E7, no de una conclusión inferida desde el nombre del paquete.
