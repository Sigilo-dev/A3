# E0-D3 media toolchain spike

This isolated spike uses only synthetic images, audio, and video generated by its own script. It never changes source files, installs global tools, or downloads media. Node/npm dependencies are local to this directory; FFmpeg and ffprobe are discovered from the existing PATH and are not downloaded by the harness.

Run `npm ci`, then `npm test`. Each run retains its generated test inputs and outputs under a new ignored `.work/run-*` directory; it does not reuse or overwrite an earlier run. The script reports the Sharp/libvips versions, supported input/output flags, FFmpeg build configuration, exact encoder/container profiles tested, source hashes, output dimensions/metadata, byte sizes, elapsed times, cancellation result, and unsupported-input diagnostics. Timings apply only to this host and these small samples. To remove only generated spike files, close Node processes and remove this spike's `.work/` directory.

The first run requires network access for the pinned npm dependency. It does not modify global software. See `docs/e0/compatibility/media-toolchains.md` for the recorded host build, license review, and limits.
